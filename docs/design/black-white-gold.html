OpenNOW · design reference

Black · Grey text · Gold Bright

Black carries the interface, a three-step grey ramp carries the words, and a single bright gold carries every point of attention. Every surface, control, and focus state on this page is drawn from the values the app's own theme tokens use, so the same decisions apply to the controller layout and to the desktop layout.

Gold bright marks exactly one thing per screen: the primary action, the current selection, or the focused surface. Text steps through grey — off-white for what you read, mid grey for what supports it, and dark grey only for chrome such as dividers and inactive glyphs, never for words on black. Content — game artwork and screenshots — keeps its own colours; only the interface is monochrome.

Desktop keeps the same vocabulary at pointer scale: hairline seams instead of drop shadows, 10 px control radii, a gold 3 px marker beside the active rail item, and a gold Play affordance on the poster under the cursor.

Rules of the system

Do

  • Baseline every surface on black; separate with a 1 px seam, not a shadow.
  • Reserve gold bright for one primary action, the current selection, and focus.
  • Step text through grey: off-white, mid grey, then grey for captions.
  • Use Outfit for headings and Inter for everything else.

Don't

  • Introduce a second accent colour, or mix in purple, orange, or neon pairings.
  • Put red and green in the same view; use gold for healthy, red only for faults.
  • Use a coloured hue to distinguish store marks — the glyph does that.
  • Set body copy in dark grey on black (1.5:1). It stays chrome-only.
